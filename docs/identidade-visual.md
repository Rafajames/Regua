A paleta foi extraída dos tokens CSS do projeto MapTec-TJRR (index.html), não estimada visualmente.

| Token | Valor | Uso |
|---|---|---|
| Navy | #0a2c63 | Navegação e estrutura |
| Navy 2 | #0d3a80 | Variação de estrutura |
| Azul | #0b4fb0 | Ações e elementos ativos |
| Azul suave | #e8f0fb | Superfícies de destaque |
| Linha azul | #cfe0f6 | Bordas de campos |
| Fundo claro | #f3f6fb | Fundo do tema claro |
| Texto | #14233d | Texto principal |
| Texto secundário | #4a5b75 | Texto de apoio |
| Destaque | #e08300 | Acentos pontuais |

## Temas
- Claro: fundo #f3f6fb, cartões brancos e texto azul-marinho.
- Escuro: fundo #0b1220, superfícies #121e30, bordas #27364d e texto claro.
- Automático: segue prefers-color-scheme do dispositivo.
- Tema escolhido fica salvo em localStorage apenas como preferência visual, sem dados de chamados.

## Princípios
Contraste legível, hierarquia simples, foco em tabelas e indicadores, animações discretas e respeito a prefers-reduced-motion. Cores de status não devem ser o único meio de comunicar o resultado.
